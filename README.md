# Portfolio — Zakaria El Arfaoui

Personal portfolio site built with [Astro](https://astro.build) and Tailwind CSS.

Showcases case studies on backend architecture, ERP platforms, and multi-tenant SaaS systems.

## Stack

- **Astro 4** — static site generator
- **Tailwind CSS** — styling
- **MDX** — case study content
- **TypeScript**

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output to dist/
npm run preview  # preview the production build
```

## Structure

```
src/
├── components/    # Astro components (Hero, About, CaseStudies, Contact, Navbar)
├── content/       # case study collection
├── layouts/       # base layout
└── pages/         # routes
```

## Deploy

Static output in `dist/`. Deployable to any static host (Cloudflare Pages, Vercel, Netlify, GitHub Pages).
